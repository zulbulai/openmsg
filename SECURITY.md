# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The OpenMsg team takes security seriously. If you discover a vulnerability or potential security risk (such as SSRF, XSS, private key exposure, or sandbox escapes), please **do not open a public GitHub issue**.

Instead, please send an email to:
**security@openmsg.dev** (or contact maintainers privately via GitHub Security Advisories).

Please include:
1. Description of the vulnerability and attack vector.
2. Steps to reproduce or proof-of-concept (PoC).
3. Assessment of potential impact.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible disclosure timeline and patch release.
