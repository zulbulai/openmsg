# Changelog

All notable changes to OpenMsg will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

---

## [0.0.1] - 2024-09-22

### Added
- Initial open-source release of OpenMsg.
- Full CRM and Kanban board for WhatsApp Web contacts.
- Chatbot builder with keyword triggers, menus, and condition routing.
- Broadcast campaign manager with rate-limiting and variable support.
- Canned responses with quick-insert keyboard shortcuts.
- AI assistant integration layer.
- Scheduler and calendar for message scheduling and contact reminders.
- Webhook integration for connecting to Zapier, Make, n8n, and custom backends.
- Privacy blur mode for contact names, numbers, and chat content.
- WhatsApp Status publisher.
- Dark and light theme support with CSS variables.

### Changed
- Rebranded from WACRM to OpenMsg.
- Removed all license gate checks — all features permanently enabled.
- Removed remote license server validation.
- Replaced yellow theme with light red (`#ff4d4f`) theme.
- Updated `manifest.json` to reflect open-source project identity.

### Removed
- License activation dialog and key input.
- Remote license server configuration.
- All marketing and support contact strings from source code.
