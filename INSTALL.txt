OpenMsg — Quick Installation
==============================

1. Clone or download the repository:
   git clone https://github.com/zulbulai/openmsg.git

2. Open your browser's extensions page:
   Chrome  -> chrome://extensions
   Brave   -> brave://extensions
   Edge    -> edge://extensions

3. Enable Developer Mode (top-right toggle).

4. Click "Load unpacked" and select the openmsg/ folder
   (the one containing manifest.json).

5. Open https://web.whatsapp.com and refresh.

The OpenMsg workspace sidebar will appear automatically.

No build step, no registration, no license key required.

For help: https://github.com/zulbulai/openmsg/issues
